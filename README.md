# 🌿 CarbonProof

**Real-Time AI & Satellite-Powered Carbon Credit Verification & Risk Intelligence Platform**

Built for **PRISM Hackathon**, organised by **NEO Club, Chennai Institute of Technology (CIT Chennai)**.

---

## 📌 About the Project

**CarbonProof** is an advanced ecological verification platform designed to address the integrity, transparency, and trust issues in global carbon credit markets. By integrating real-time satellite telemetry, IoT canopy sensors, drone SAR LIDAR data, and automated AI risk engines, CarbonProof provides verifiable, immutable, and transparent data for carbon offset projects worldwide.

### 🚩 Problem Statement
Traditional carbon markets suffer from:
- **Greenwashing & Double Counting:** Lack of immutable cryptographic tracing.
- **Outdated Verification Cycles:** Audits often take months or years while deforestation occurs unnoticed.
- **Opacity in Project Health:** Buyers have minimal insight into real-time canopy density, biomass shifts, or thermal anomalies.

### 💡 Solution & Vision
CarbonProof creates dynamic **Carbon Credit Passports** linked to continuous geospatial and ecological telemetry. Projects are constantly monitored through satellite imagery (Sentinel-2B), multispectral NDVI vegetation tracking, and AI anomaly detection—ensuring that every issued credit corresponds to verified, living biomass on the ground.

---

## ✨ Key Features

- **🌐 Live Geospatial Intelligence Map:**
  - Interactive global radar canvas displaying monitored reforestations, mangrove restorations, and conservation projects across South America, Africa, SE Asia, and North America.
  - Live spatial project selection with instant metric updates (Risk Score, Hectares, Vintage, Coordinates).

- **📜 Cryptographic Carbon Credit Passports:**
  - Inspect individual carbon credit tokens (e.g., `CP-2026-AMZ-09412`) with Merkle Root hashes, serial numbers, and full verification audit logs.
  - Transparent tracking of telemetry history including NDVI scores, canopy density, biomass (t/ha), radar backscatter, soil moisture, and carbon flux.

- **🤖 AI Risk Engine & Real-Time Anomaly Detection:**
  - Autonomous monitoring for canopy loss, thermal spikes, unregistered land clearing, and IoT mesh disconnections.
  - Categorized severity alerts (`ACTIVE`, `RESOLVED`, `AUTO-CLEARED`) to safeguard credit investors.

- **🔬 Telemetry & Sensor Integration:**
  - Synchronizes multi-source data from Sentinel-2B, Drone SAR LIDAR, Canopy Mesh IoT nodes, and registry standards (e.g., Verra).

- **🎨 Futuristic Radar & Contour UI:**
  - Custom HTML5 Canvas rendering interactive orbital trajectories, satellite radar pulses, topography contours, and micro-animations.

## 🚀 Getting Started

### Prerequisites

Ensure you have **Node.js** (v18 or higher) and `npm` or `yarn` installed.

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/your-username/CarbonProof.git
   cd CarbonProof
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run the development server:**
   ```bash
   npm run dev
   ```

4. **Open application in browser:**
   Navigate to [http://localhost:3000](http://localhost:3000).
